Overalls server

Choose the Overalls server where repository pages open. HTTPS is required; HTTP is accepted only for loopback development.

Need installation help? Read the browser extension guide.

How it works

  1. Open a repository page on GitHub, GitLab, Codeberg or Bitbucket Cloud.
  2. Click the toolbar button. Only the provider origin and page path are sent to your server.
  3. Sign in if needed; Overalls creates the machine and clones the repository.

No page contents, credentials, history or telemetry leave the browser. Unsupported pages keep the button disabled or show a short ! badge.
