# Glyphs

`<.glyph name="…" />` renders one cell of JetBrains Mono, `aria-hidden` unless
`label` is given. Names and characters (MarshallWeb.CoreComponents):

| name | glyph | name | glyph |
| --- | --- | --- | --- |
| arrow_up_right | ↗ | caret_down | ▾ |
| arrow_left / arrow_right | ← → | caret_right | ▸ |
| arrow_up / arrow_down | ↑ ↓ | triangle_right / triangle_down | ▶ ▼ |
| return | ↩ | menu | ≡ |
| refresh | ↻ | plus / minus | + − |
| check | ■ | bang | ! |
| cross | × | info | i |
| bullet / circle / square | ● ○ □ | search | / |
| diamond | ◆ | copy | ⎘ |
| home | ⌂ | star | * |

Text conventions: status `[running]`, `[stopped]`, `[failed]` (brackets from
CSS); progress ladders `[■] done [▸] current [ ] pending`; external links end
with `↗`; navigation back links start with `←`; the sidebar tree draws its own
connectors. Box drawing (`─ │ ┌ ┐ └ ┘ ├ ┤ ╭ ╮ ╰ ╯ ▀ ░ █`) belongs in `<pre>`
inside `<figure>` with a `<figcaption>`.
