# Historical documentation

This directory preserves recovered plans and implementation ledgers whose
revision-specific evidence remains referenced by architecture decisions,
reviews, or handbook scenarios. These pages are historical records, not current
runbooks, and their test statements retain their original scope.

The current archive contains the ledgers in [`ledgers/`](ledgers/). Future
removal requires an evidence review that retires every inbound reference and
updates the affected architecture and HLDD records.
