# Mila M1: client, transport and host trust (2026-10-18)

Scope: [ADR-0220](../decisions/0220-mila-client-over-porsche-ssh.md),
[ADR-0221](../decisions/0221-canonical-app-routes.md),
[ADR-0222](../decisions/0222-porsche-client-commands.md),
[ADR-0226](../decisions/0226-monospace-web-on-flutter.md),
[ADR-0227](../decisions/0227-flutter-toolchain-and-dartssh2-overlay.md) and
[ADR-0228](../decisions/0228-strict-host-certificates-in-mila.md). Reviewed
against the uncommitted working tree on branch `feat/mila-m1`, based on
`a03df486`.

## Findings

1. **Boundary:** Mila adds no Ash domain, host or Marshall API. Its only
   deployment paths are Porsche SSH and the public trust document. Authority
   stays in Marshall; Mila holds a device key and pinned trust, nothing else.
2. **Identity:** Each deployment gets its own P-256 key. Porsche proves
   possession only after a signature, as for any client key; P-256 acceptance
   is now tested through real OpenSSH.
3. **Transport trust:** Host acceptance runs during key exchange, before user
   authentication, against the pinned CA and the management host. With the
   check disabled, the CA, principal and expiry refusal tests fail, so they
   exercise it.
4. **Dependency:** dartssh2 is pinned by archive hash and patched in one
   reviewed patch with a directory contract. Its existing async identity
   interface covers hardware signers, so no signer patch was needed.
5. **Links:** Following a link is navigation only. Platform deep linking is
   disabled, so the deployment host in a link cannot be dropped.
6. **Gap — native custody:** The Swift and Kotlin key custody and link delivery
   have not been compiled or run on a device.
7. **Porsche interop:** The `mila-porsche` machine test passed against the
   real Porsche release on trunk `8ef701ce`: a rogue CA and a certificate for
   another host are refused without a Porsche authentication record, and the
   pinned CA's certificate with the device key authenticates. Marshall is absent
   in that fixture, so the command itself ends in an `authority` envelope.
8. **Gap — Marshall:** The `pinned`/`route` wire changes and the machine-state
   fixture test have not run, because Marshall does not compile on the base
   for a pre-existing reason.
9. **Observation:** The web glyph table includes `↻` and `⎘`, which JetBrains
   Mono lacks; Mila avoids them (ADR-0226 open question).
