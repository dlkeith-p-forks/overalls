# Authenticated handbook and mandatory upkeep

## Scope and architecture impact

ADR-0121 adds an authenticated static handbook, pinned local Mermaid dependency,
and mandatory source/evidence maintenance. It preserves ADR-0119's distinction
between current signed-in reading and administrative mutation. ADR-0001 and
ADR-0028 continue to govern evidence and contracts. Domain authority, protocol,
persistence and guest isolation are unchanged.

## Review findings

The public documentation catalog is deliberately separate. The handbook performs
no operational queries. Current-login hooks protect initial access and subsequent
navigation/events. Raw HTML originates only in compiled reviewed Markdown; Mermaid
uses strict policy without links, source directives or HTML labels.

The source receipt gate establishes reviewed inventory currency, not prose truth.
Scenario evidence distinguishes test presence from recorded execution and retains
native/property coverage gaps. Historical database reactivation remains explicitly
unverified; passing documentation checks does not narrow that gap.

## Remaining gaps

The handbook's scenario ledger records system-level native, property, provider and
physical acceptance gaps. This documentation change does not implement those
missing platform capabilities. Production activation remains to be observed after
the authorized merge and push.
The nested security diagram renders on mobile but needs a readability follow-up;
the adjacent prose and table retain every boundary and testing gap.

## Reader authority evidence correction

The verification campaign found that this native seed left installation bootstrap
incomplete. Its first magic-link login promoted the seeded reader to administrator.
The original ordinary-user native claim is withdrawn. Rendering, navigation,
fixture TLS and anonymous/public-route refusal results retain their actual scope;
this run did not revoke a session. Application-level ordinary-user and revoked
navigation tests remain separate evidence. The
[reader authority review](2026-09-25-handbook-reader-verification.md) records the
corrected fixture, persisted role assertions and new native refusal checks.
