# Mila M6: integrated client, relay and verification (2026-10-19)

Scope: [ADR-0220](../decisions/0220-mila-client-over-porsche-ssh.md) through
[ADR-0228](../decisions/0228-strict-host-certificates-in-mila.md) on the
integrated `feat/mila` tree. That tree combines:

- the Mila client: M1–M5;
- the Porsche client commands, ReadMarker and `watch` (ADR-0222);
- Porsche terminal attach (ADR-0223);
- the Marshall Notifications domain (ADR-0225);
- the Susan relay (ADR-0224).

Boundaries reviewed at integration:

- **One protocol, one fixture per contract.** These are shared by Elixir,
  Dart and Swift:
  - command catalog: `OverallsProtocol.SSHCommand`;
  - routes: `AppRoute`;
  - E2E pokes: `PushPoke`;
  - Susan wire body: `SusanPoke`.

  Each side tests against the same fixture under `protocol/test/fixtures/` or
  `protocol/priv/`. The one cross-workstream divergence was found here and fixed
  in code: what the Susan signature covers. See the
  [Susan review](2026-10-19-susan-push-relay.md).
- **Authority stays in Marshall.** Mila holds no authority of its own. Every
  operation goes through a Porsche SSH session bound to a device key. Push pokes
  carry only a sealed route, and Mila fetches the details over SSH.
- **Merged shared surfaces.** The command catalog groups, `ssh/commands.ex`
  dispatch, `control_requests.ex` refusal mapping, the Porsche client reasons and
  runner hints, the gettext catalogs and the Events catalogs were combined by
  union. No workstream's entries were dropped.
- **Placement.** Susan stays outside every fleet host. Marshall's only new egress
  is the compiled Susan origin.

Decision status: all of ADR-0220–0228 remain `accepted`, implementation `partial`.

### Follow-up: remaining Mila items (2026-10-19)

- **iOS notification extension.** The `NotificationService` app-extension
  target is now in `Runner.xcodeproj`. It is embedded in Runner, depends on
  it, has Debug, Release and Profile configurations and the bundle id
  `dev.overalls.mila.NotificationService`, and is signed with the shared
  Keychain group. Runner signs with `Runner.entitlements`. The project file
  parses with `openstep-parser` 2.0.3, and every object reference resolves.
  Xcode is unavailable, so nothing was built or signed.
- **Noto fallbacks.** These follow ADR-0207 and ADR-0226.
  `nix/domains/artifacts/mila/fonts.nix` fetches the original faces that
  Marshall's manifest pins, by digest, each with its OFL notice. The theme and
  terminal fall back to them behind JetBrains Mono. The three Arabic goldens
  changed from boxes to shaped Arabic and were reviewed. The light, dark and
  Arabic machine goldens gained the new-machine button.
- **Remaining plan features.** Create, clone and resize, and machine sharing
  (`share show`, `share add`, `share remove`) with a new `MonoTable` widget.
  The new code has Hegel properties in `mila_core` and widget tests against
  the fake Porsche.
- **Android Nix build.** `nix/domains/artifacts/mila/android.nix` is exposed
  as the flake package `tool-mila-android`, which no check or workflow lists.
  It uses androidenv (platform 36, build-tools 36.0.0, NDK 28.2.13676358),
  JDK 17 and Gradle 9, with a recorded mitm-cache lock (`android-deps.json`).
  `nix build .#tool-mila-android` succeeded offline in the sandbox. It
  produced a 39.8 MB arm64 APK (`dev.overalls.mila` 0.1.0, minSdk 24,
  targetSdk 36) that contains the Noto assets. After that build, only a
  comment changed in `android.nix`, and the package still evaluates.
- **Recorded runs** inside `devenv shell`:
  - format and analyze (`--fatal-infos`) are clean;
  - `mila_core`: 144 tests;
  - `mila_transport`: 41 tests;
  - app: 68 tests, including 6 goldens;
  - the Nix checks `mila-lock-sync`, `mila-core` (144), `mila-transport` (41)
    and `mila-test` (68) pass;
  - `mila-desktop` passed with 7 subtests (98.5 s test script time).

## Gaps

- iOS and Android device builds. The iOS notification extension is in the
  Xcode project but has not been built, signed or run.
- A machine test that drives Mila's create, clone, resize and sharing
  commands against a real Porsche. Only the fake Porsche covers them.
- Variable Noto weights: the fallbacks render at their default instance, and
  the engine synthesizes bold.
- Real APNs and FCM delivery.
- Real values in `secrets/overalls-susan.enc.json`: the document exists with
  placeholder values, recovery-only, with no Susan host recipient.
- Susan hosting, registry and TLS placement.
- The Nix Android APK has not been installed or run. It is signed with the
  debug key, built for arm64 only and has no FCM configuration. Its Gradle
  lock must be re-recorded with network access, and on this host only with
  `USE_BWRAP=0`, after any change to the Android Gradle plugin, Kotlin,
  Firebase, a Flutter plugin or Gradle.
- Model-executed turns and committed-hint delivery to a watch in a fleet
  journey.
- Native-speaker review of machine-filled Mila and Porsche translations,
  including the 25 new Mila messages, and device verification of each
  script's shaping.
