# Overalls typefaces

JetBrains Mono is Marshall's primary typeface and defines the character grid.
The Monospace Web presentation uses weights 500 (normal), 600 (medium) and
800 (bold) plus the 500 italic. Script fallbacks cover the configured
languages (ADR-0207). Every face uses `font-display: swap` through
`assets/css/fonts.css`; every request stays on the application origin.

| File | Upstream face | Weight / style |
| --- | --- | --- |
| `jetbrains-mono-500.woff2` | `JetBrainsMono-Medium.woff2` | 500 normal |
| `jetbrains-mono-500-italic.woff2` | `JetBrainsMono-MediumItalic.woff2` | 500 italic |
| `jetbrains-mono-600.woff2` | `JetBrainsMono-SemiBold.woff2` | 600 normal |
| `jetbrains-mono-800.woff2` | `JetBrainsMono-ExtraBold.woff2` | 800 normal |

Source: the upstream release archive `JetBrainsMono-2.304.zip` from
<https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>
(`fonts/webfonts/`, SHA-256 of the archive
`6f6376c6ed2960ea8a963cd7387ec9d76e3f629125bc33d1fdcd7eb7012f7bbf`). The
WOFF2 files are copied unchanged; glyphs were not subsetted. The adjacent
`jetbrainsmono-OFL.txt` preserves the SIL Open Font License 1.1 and copyright
notice. Digested and gzip copies are generated by Phoenix's asset build and are
ignored by Git.

## Localization fallbacks

| File | Complete upstream face | Coverage |
| --- | --- | --- |
| `noto-cjk.woff2` | Noto Sans Mono CJK SC Regular 2.004 | Han, Japanese kana and Korean Hangul; OpenType Japanese/Korean/Chinese regional forms |
| `noto-arabic.woff2` | Noto Sans Arabic variable | Arabic, Egyptian Arabic and Urdu, including extended letters and Urdu shaping |
| `noto-devanagari.woff2` | Noto Sans Devanagari variable | Hindi and Marathi |
| `noto-bengali.woff2` | Noto Sans Bengali variable | Bengali |
| `noto-telugu.woff2` | Noto Sans Telugu variable | Telugu |
| `noto-tamil.woff2` | Noto Sans Tamil variable | Tamil |
| `noto-mono.woff2` | Noto Sans Mono variable | Extended Latin, including Hausa hooked letters |
| `noto-symbols.woff2` | Noto Sans Math Regular | Symbols missing from JetBrains Mono, including the reconnect arrow |

The eight fonts total 13,815,920 bytes (13.18 MiB). They are complete fonts,
without translation-dependent glyph subsets. Their shaping tables, variable
weights and regional substitutions are preserved. Native shaping takes
priority over fixed character advances in Arabic and Indic text. The CJK
face has half-width Latin and full-width CJK advances; the surrounding layout
continues to use JetBrains Mono's `1ch` grid. The regular CJK face uses browser
synthetic bold/italic where needed; the six variable fallbacks provide weights
100–900, including the extended Latin fallback. CSS Unicode ranges load only
the scripts a page uses. A language
selector showing every native language name consequently loads every fallback.

The adjacent `noto-fonts.json` pins immutable upstream commits and SHA-256
digests for original fonts, served WOFF2 bytes and individual OFL notices.
The upstream fonts and licences remain available in the pinned source paths;
no build or browser fetches them at runtime. Glyph coverage was checked against
all current Marshall/Porsche catalog text and all 28 CLDR native locale names.
This checks character availability and preservation of shaping tables. It does
not establish correct browser shaping; browser direction and layout observations
are recorded separately.

Verify vendored bytes without network access or optional tools:

```sh
python3 scripts/vendor_localization_fonts.py --check
```

Check all Marshall/Porsche PO source and translated text against the primary
font and fallback cmaps **intersected with their CSS Unicode ranges**:

```sh
python3 scripts/vendor_localization_fonts.py --check --check-glyphs
```

This mode requires the `fonttools` executable from the Nix shell below. Include
the current native language labels by exporting them from an already compiled
Marshall application in the pinned development shell, then supplying the
temporary UTF-8 file (keep it outside the repository):

```sh
cd marshall
elixir -pa "_build/test/lib/*/ebin" -e 'Application.put_env(:localize, :locale_cache_dir, Path.expand("priv/localize/locales")); Application.put_env(:localize, :allow_runtime_locale_download, false); Application.ensure_all_started(:localize); File.write!("/tmp/overalls-native-locale-names.txt", Enum.map_join(Marshall.Localization.options(), "\n", fn {name, _locale} -> name end))'
cd ..
python3 scripts/vendor_localization_fonts.py --check --check-glyphs \
  --text-file /tmp/overalls-native-locale-names.txt
```

Reproduce from the repository root using its locked package input (FontTools
4.63.0 and Brotli 1.2.0). Conversion preserves original timestamps and does not
subset or modify glyphs. It refuses unexpected source or output bytes:

```sh
nix shell --impure --expr 'let f = builtins.getFlake (toString ./.); p = import f.inputs.buildNixpkgs {}; in p.python313.withPackages (x: [ x.fonttools x.brotli ])' \
  --command python scripts/vendor_localization_fonts.py
```
