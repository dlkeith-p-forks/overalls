# Overalls Antithesis fallback SDK

This package is harness-only. It implements the documented [fallback SDK](https://antithesis.com/docs/reference/sdk/fallback/) for Elixir because the published [SDK list](https://antithesis.com/docs/reference/sdk/) does not include BEAM. It emits assertion and lifecycle JSONL to `$ANTITHESIS_OUTPUT_DIR/sdk.jsonl`; it is not an official Antithesis SDK and does not establish BEAM code coverage, thread pausing, or symbolization. A successful local append is not a hosted ingestion acknowledgment.

The package is included in Overalls releases only when `ANTITHESIS_HARNESS=1` is set during the harness build. The image must compile `native/sdk_writer.c` to `/opt/antithesis/sdk_writer`, set `OVERALLS_ANTITHESIS_WRITER` to that absolute executable path, and provide a private writable directory through `OVERALLS_ANTITHESIS_STATE_DIR` (the image uses `/var/lib/overalls-antithesis-sdk`). The helper holds a nonblocking file lock so only one helper may use that container's output stream. Before each append, it synchronizes an `inflight` marker in that private directory; only a complete write removes it. A restarted helper refuses a leftover marker without reading the output sink. The helper validates complete JSON object framing, UTF-8 and JSON syntax, then uses one `O_APPEND` write syscall for each bounded JSONL record. It never opens the output sink for reading, rewriting, rotation, or rename. One BEAM application instance admits one in-flight record to its helper. A short write, failed/late acknowledgment, or port failure poisons the writer; `OverallsAntithesis.SDK.status/0` then reports `:poisoned`, including after a supervised SDK application restart in the same BEAM instance, and callers receive an explicit error. The run must be treated as incomplete evidence. Each image runs one SDK writer process for its own container output directory; concurrent independent BEAM instances in one container are refused by the private lock. The sink is a special Antithesis output directory in hosted runs and cannot be read back there. A normal local directory may be used for focused tests.

Each assertion call uses one literal message that also serves as its stable string ID. Each module with calls exports `__antithesis_catalog__/0` automatically. The coordinator must pass the union of every property-bearing module to `declare_catalog/1` before test execution, including assertions in test commands that may never run. `catalog/1` rejects duplicate messages across modules, and `export_catalog/2` writes the exact declaration records from compiled callsites to an absolute local path for image review. A separate container may redeclare the same catalog. `setup_complete/0` emits the exact documented `{"antithesis_setup":{"status":"complete"}}` record, but only the single readiness coordinator calls it after readiness and catalog publication; the SDK never calls it on application startup.

```elixir
defmodule OverallsAntithesis.ExampleOracle do
  require OverallsAntithesis.SDK

  def observe(ready?) do
    OverallsAntithesis.SDK.always("Overalls example readiness is retained", ready?)
  end
end

OverallsAntithesis.SDK.declare_catalog([OverallsAntithesis.ExampleOracle])
```

The macro family is `always/2,3`, `always_or_unreachable/2,3`, `sometimes/2,3`, `reachable/1,2`, and `unreachable/1,2`. Conditions are already-observed booleans. Optional details must be a `%OverallsAntithesis.SDK.Details{}` with reviewed, bounded numeric fields; arbitrary strings, payloads, credentials and nested maps are refused. The writer deduplicates each assertion's first true and first false evaluation only after a complete write. Declarations use `hit:false`, `condition:false`, and no details; evaluations use `hit:true`. Reachable and Unreachable evaluations force true and false respectively. The exact field mapping follows the [fallback assertion specification](https://antithesis.com/docs/reference/sdk/fallback/assert/) and [schema](https://antithesis.com/docs/reference/sdk/fallback/schema/).

`choose/1` reads fresh bytes from `/dev/urandom` for each draw and uses rejection sampling for an unbiased index. It does not seed a stateful PRNG. This uses the intercepted system random device described by the [randomness guide](https://antithesis.com/docs/reference/sdk/generate_randomness/); it cannot provide the structured feedback of an official language SDK.

For local verification, run `mix deps.get`, `mix format --check-formatted`, `mix compile --warnings-as-errors`, and `mix test` from this directory. Tests compile the C helper with `SDK_WRITER_TEST_FAULTS` to enable short-write and delayed-reply injection; the image build omits that define. The tests use ordinary temporary output and state directories and cover declaration/evaluation matching, deduplication, malformed JSON, short-write poisoning across SDK and helper restarts, and acknowledgment timeout. The private marker prevents a partial record from being followed by another record after a helper restart; it does not establish exactly-once delivery if a complete write loses its reply. Hosted validation must independently confirm catalog ingestion, setup recognition and actual instrumentation; local tests establish only the adapter behavior.
