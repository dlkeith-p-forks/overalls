# galileo-named-origin-credential-and-revocation-bound

P0 safety; high design confidence, medium composed feasibility. Canonical candidate. Primary `Always` message: **"Named integration uses its authorized origin and headers and stops after revoked renewal"**. At every independently observed upstream attempt, the origin and injected headers must match its authorized grant snapshot, whose admission checked the then-current source execution and attachment; detachment or other authority withdrawal must refuse a later new request and close an existing request on its next refused/expired renewal, without a retry or changed target. The assertion checks effect history, not guest HTTP status. Antithesis instrumentation is missing according to `antithesis/scratchbook/existing-assertions.md`.

## Source and accepted boundary

ADR-0080 `:25-43` gives a single-label private name, fixed HTTPS origin, platform-computed injected credentials, one upstream attempt and bounded renewal. ADR-0134 `:20-31` requires explicit personal attachment even for an owner's VM and renewal recheck. `audi/lib/audi/private/front.ex:127-143,178-193` selects the Galileo Unix socket, filters guest headers and supplies canonical Host plus pre-NAT binding. `galileo/lib/galileo/http.ex:67-99` validates name/binding and asks Marshall on each request; `:98-133` performs accounting then one stream call. `marshall/lib/marshall/galileo/authorizations.ex:21-52,61-71,106-120,162-213` selects target/headers from the live integration and repeats owner, attachment, host and execution fences on renewal. `protocol/lib/overalls_protocol/integration.ex:46-73,89-113,149-192` closes target/header/authorization and renewal wire shapes. `galileo/lib/galileo/upstream.ex:32-44,71-105,112-160` uses verified TLS, selects the response's origin, overrides injected-name guest copies and starts one request; `:411-551` renews or closes the attempt. These are claimed/implemented code paths to test under faults, not proof that the composed property passes.

## Independent effect and authority oracle

Provision two distinct local HTTPS origins A and B with separate immutable accept/request logs and synthetic fixture certificates. Configure one personal integration name for A, one strip prefix, and a fixture-only static header plus fixture-only bearer/basic credential. Store expected header values only in the protected fixture process; export to the assertion only booleans `target_is_A`, `path_matches`, `injected_headers_match`, `guest_duplicate_was_overridden` and per-origin counters. Never print or persist credential values, incoming raw headers, request bodies, URL query, tool payload, prompt or terminal bytes. From a genuinely attached, running source VM send a fixed nonce-labeled GET or bounded POST through the normal `.integration.internal` DNS/Audi path. A valid control request must produce exactly one A effect with the configured path and header predicates true, zero B effects and one response. A guest-supplied duplicate `Authorization` or configured static-header name must not replace the platform-computed value. A guest-selected Host or forwarding/binding header cannot select B.

Hold an A response or upload open across at least one successful renewal. Then commit detachment, integration removal or owner/team authority withdrawal and observe the first refused renewal, A socket EOF/reset and no new accepts under the old authority. Bytes already buffered before refusal may still be read at A; do not misclassify those as new forwarding. Send a new request after the committed withdrawal; the independent origin logs must show no new attempt. Reattach under current authority and send a genuinely new request to show availability is not the reason for refusal. Configuration changing from A to B should affect only a newly authorized request; an already-open A attempt retains its selected target/credential until cancelled or naturally finished. A response failure or timeout is not evidence that no origin effect happened, and a successful renewal before detachment may legitimately allow bytes until the next refusal/expiry. The workload must record ordering using committed Marshall mutation/renewal receipts and origin timestamps, not assume a wall-clock race winner.

Potential supplementary `Reachable` **"Galileo detached attachment refused a fresh named request"** marks an exercised refusal; `Sometimes(condition)` **"Galileo renewed an open named request before withdrawal"** is a meaningful successful-renewal state. They require distinct messages. The existing `galileo-accounting-delay-does-not-renew-old-grant` remains a separate original-grant timing test; here the oracle primarily tests name/config/header/current attachment and the actual effect count.

## Fault/value menu and scope

Vary attached/unattached owner VM, team member/withdrawn member, current/stale placement or execution epoch, normal/changed configuration, guest duplicate header present/absent, first authorization unavailable/late, successful/refused/invalid/late renewal, A response held before headers/after partial bytes, upload blocked in owner, Galileo restart and origin connection loss. The native `integration-renewals` fixture already counts accepts/connection and active requests at `nix/tests/machines/integration-renewals/driver.py:49-135`, while the upstream unit property exercises partial prefixes at `galileo/test/upstream_test.exs:76-129`; neither proves the full two-origin/header/guest identity permutation in this candidate. A service-only hosted test can verify Marshall/Galileo policy with controlled binding but cannot claim a real guest originated the request. Complete claim needs Audi/Lilly current pre-NAT binding and guest network path; TCG does not establish physical network isolation, real public service behavior or separate physical hosts.

Open question: Can a hosted integration fixture retain Audi's actual pre-NAT source binding and live A socket while detaching/configuring through ordinary Marshall authority? `(partial: native renewal fixture has real guest/socket precedent; selected hosted integration composition is not built)`
