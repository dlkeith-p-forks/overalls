# inception-parent-publication-cannot-confer-child-authority

**Type/priority/status:** Safety, P0, medium-high confidence; proposed and unimplemented. Primary `Always(condition, "Inception nested forwarding requires a current parent lease and child effects require child authorization")`. Check each newly forwarded protected byte against parent stream authority at forwarding time, and each inner operation's admission against the child's independently current principal/permission. An operation accepted by the child before parent expiry may settle later; settlement time alone is not a violation. `Always` is the correct must-hold semantic for every observed forwarding or admission, including optional profile runs. A separate `Sometimes(authorized_child_effect_after_valid_parent_stream, "Authorized Inception child effect crosses both authority layers")` is mandatory in the Inception native template: it is a meaningful positive reach witness, not `Sometimes(true)` or a refusal counted as coverage. A rare branch `Reachable("Stale Inception parent stream is refused after publication change")` may guide replay, but the byte oracle decides safety. No current SDK assertion exists (`antithesis/scratchbook/existing-assertions.md`).

**Invariant and boundary:** The parent may route only a listener in a currently enabled Inception namespace with current host session, placement, execution epoch, VM/environment generation and unexpired child publication. The child independently authenticates and authorizes its user or SSH key; a parent stream grant does not become child membership. New protected bytes must stop crossing the parent gateway after the lease deadline if renewal is blocked or refused, even while the child remains alive. Conversely, a valid parent lease cannot allow an unauthenticated or child-revoked actor's new inner mutation/read. Ordinary outer web membership and outer guest readiness do not imply this two-level condition.

**Source and accepted contract:** `marshall/lib/marshall/ingress/environment_publications.ex:16-23,27-47,60-67,120-141` authenticates exact host/execution/environment and limits offers/results to the original five-second deadline. `marshall/lib/marshall/ingress/environment_authority.ex:6-46` checks enabled namespace, publication binding/expiry and selected child listener. `marshall/lib/marshall/ingress/environment_streams.ex:26-31,32-76,79-100` opens and renews short parent stream leases without granting child membership. `audi/lib/audi/inception/authority.ex:7-11,47-86` guards the connection owner independently of a blocked renewal; `audi/lib/audi/inception/front.ex:75-105,117-132` forwards actual socket bytes only after grant/connector admission. `nix/packages/guest/inception/runtime.py:84-160` generates separate inner identities; `nix/packages/guest/inception/roles.py:71-89,101-134` uses verified local control TLS and independent inner gateway credentials. ADR-0106:13-32,54-67 requires independent child authorization and bounded parent publication. The native fixture exercises two inner environments and real nested guests (`nix/tests/machines/inception/driver.py:212-266`), but its presence is not current execution proof.

**Independent oracle:** Use two real source-built Inception environments A/B with separate inner databases, credentials and namespaces. Keep workload-owned nonce ledgers outside the SUT: one parent public TLS/SSH client records byte-level request/response and certificate/host-key identity, and one child-side authenticated endpoint or nested guest file records successful nonce-bearing effects and owning child principal. Read parent durable `EnvironmentPublication`/`EnvironmentStream` binding and independent current outer boot/host-session evidence; query child membership/operation rows through its own authenticated control plane. Compare each fresh request's forwarding time to its parent authority interval and its inner admission time to child permission. A request already admitted before revocation must be classified separately from new post-revocation work. Do not treat a Control reply, successful TCP connect, SUT event or a timeout as an effect oracle. Do not log tokens, raw credential/certificate secrets, terminal contents or user payloads; synthetic nonce hashes suffice.

**Action/fault interleavings:** Establish a positive child-authorized HTTPS/SSH operation through A, then attempt the same path using a valid parent stream but a child-denied actor/key. During an admitted A stream, disable its parent namespace or advance environment generation, rotate the outer host session, replace the outer physical boot, and delay/replay the child publication reply. Block or kill renewal while retaining the socket owner; after the original lease deadline, send a new synthetic protected request and check that neither client nor child effect ledger advances. Restart child Marshall/Audi and parent gateway separately, preserving B's live authorized effect as a neighbor-progress control. Re-enable A under a new binding and require fresh admission/child auth for a successful effect. A child process still listening during parent denial is intentional; a failed connect alone is inconclusive.

**Value menu and branch guidance:** HTTPS control versus Audi application listener; Porsche versus Audi nested SSH; child actor authorized/revoked/foreign; A versus B namespace; current/expired/replayed publication; current/stale host session, execution epoch, VM and environment generation; renewal success/blocked/definitive refusal; outer stop/start and child service restart. Candidate SUT-side search anchors are `EnvironmentPublications.accept!/4` (old offer/result), `EnvironmentAuthority.current!/3` (stale publication), `EnvironmentStreams.perform(:renew_nested, ...)` (no resurrection), and `Audi.Inception.Authority.renew_now/6` (guard expiry). Branch observations should carry opaque IDs and closed reason enums only; the independent byte ledger remains decisive.

**Environment and proof boundary:** Primary physical assertion requires native nested KVM, real Firecracker/ZFS for both outer and inner VMs, current image/proof admission, local PostgreSQL/Marshall/Lilly, parent Audi and public fixture DNS/TLS. Hosted `control-core` can validate parent transaction and lease logic but cannot prove recursive child physical authority. TCG `guest-vmm` can boot an ordinary guest but is not the source-built native Inception stack. The nested image must be rebuilt from a pinned offline cache (`nix/packages/guest/inception/image-builder.nix:54-81`), not downloaded at runtime. Two inner environments on one physical builder prove logical boundary isolation, not independent host failure domains. Safety continues under faults; positive `Sometimes` is required only after exact parent, child and guest dependencies have been restored and observed ready.
